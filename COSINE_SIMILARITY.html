🤔 Apa itu Cosine Similarity?

Penjelasan paling sederhana

📖 Definisi Resmi:

Cosine Similarity adalah metode untuk mengukur kemiripan antara dua vektor (kumpulan angka) dengan cara melihat sudut di antara mereka.

🍼 Bahasa Sederhana:

"Seberapa SEARAH dua hal ini?" — kalau searah berarti mirip, kalau berbeda arah berarti tidak mirip.

📊 Hasilnya berupa angka:

SkorSudutArtiContoh
1.00°Sangat mirip"Indomie Goreng" vs "Indomie Pedas"
0.745°Mirip"Indomie" vs "Sarimi"
0.090°Tidak terkait"Indomie" vs "Sabun Mandi"
-1.0180°Berlawanan(Jarang terjadi di teks)

📐 Rumus Matematika

Yang akan ditanya dosen!

cos(θ) = (A · B) / (||A|| × ||B||)

Penjelasan Komponen:

1️⃣ A · B (Dot Product / Perkalian Titik)

Kalikan tiap elemen yang sama, lalu jumlahkan semuanya.

A · B = (a₁ × b₁) + (a₂ × b₂) + ... + (aₙ × bₙ)

2️⃣ ||A|| (Magnitude / Panjang Vektor)

Akar kuadrat dari jumlah semua elemen yang dikuadratkan.

||A|| = √(a₁² + a₂² + ... + aₙ²)

💡 Cara Mengingat:

Atas: Kalikan satu-satu, lalu jumlahkan
Bawah: Kuadratkan satu-satu, jumlahkan, akar kuadrat — untuk masing-masing vektor, lalu kalikan keduanya

🧮 Hitungan Manual (Contoh Kecil)

Pakai vektor 3 dimensi biar mudah dipahami

📦 Bayangkan kita punya 2 produk:

Misalkan setiap produk diwakili oleh 3 angka: [manis, asin, pedas]

ProdukManisAsinPedas
🍜 Indomie Goreng0.20.70.6
🍜 Indomie Soto0.10.80.5

📝 Langkah Hitung:

1

Hitung Dot Product (A · B)

A · B = (0.2 × 0.1) + (0.7 × 0.8) + (0.6 × 0.5)
= 0.02 + 0.56 + 0.30
= 0.88
2

Hitung ||A|| (panjang vektor A)

||A|| = √(0.2² + 0.7² + 0.6²)
= √(0.04 + 0.49 + 0.36)
= √0.89
= 0.943
3

Hitung ||B|| (panjang vektor B)

||B|| = √(0.1² + 0.8² + 0.5²)
= √(0.01 + 0.64 + 0.25)
= √0.90
= 0.949
4

Masukkan ke rumus utama

cos(θ) = 0.88 / (0.943 × 0.949)
= 0.88 / 0.895
= 0.983 ≈ 98%

✅ Kesimpulan:

Skor 0.983 → SANGAT MIRIP (98%) — masuk akal karena keduanya sama-sama Indomie!

💻 Penerapan di Project (Codingan)

Bagaimana cosine similarity dipakai di app Yeti Smart Retail

1. Edge Function: Generate Embedding

Setiap produk diubah jadi vektor 384 dimensi oleh AI:

// supabase/functions/generate-embedding/index.ts const session = new Supabase.ai.Session('gte-small'); serve(async (req) => { const { input } = await req.json(); // Generate vektor 384 dimensi dari teks const embedding = await session.run(input, { mean_pool: true, normalize: true // PENTING: vektor sudah dinormalisasi }); return Response.json({ embedding }); });

2. Simpan Embedding ke Database

Saat admin tambah produk, embedding disimpan ke kolom embedding VECTOR(384):

// admin_dashboard.dart final textToEmbed = "${nameCtrl.text} - ${descCtrl.text}"; // Panggil Edge Function final response = await Supabase.functions.invoke( 'generate-embedding', body: { 'input': textToEmbed } ); // Simpan ke database await supabase.from('products').insert({ 'name': nameCtrl.text, 'embedding': response.data['embedding'], // 384 angka });

🗄️ SQL Function di Database

Cara hitung similarity langsung di PostgreSQL

CREATE FUNCTION get_similar_products( query_embedding VECTOR(384), match_threshold FLOAT DEFAULT 0.70, match_count INT DEFAULT 50 ) RETURNS SETOF products LANGUAGE sql STABLE AS $$ SELECT * FROM products WHERE embedding IS NOT NULL AND 1 - (embedding <=> query_embedding) >= match_threshold ORDER BY embedding <=> query_embedding LIMIT match_count; $$;

⚠️ Operator <=> dari pgvector

Operator ini menghitung cosine distance (= 1 - cosine similarity).
Jadi: 1 - (a <=> b) = cosine similarity

OperatorArtiHasil
<=>Cosine distance0 = sama, 2 = berlawanan
